# Customer Shopping Behavior Analysis

## About the Project

This project is about understanding customer shopping behavior by analyzing shopping data using Python, MySQL, and Power BI.

I started by loading the dataset into Python, exploring the data, and cleaning it to make it ready for analysis. After that, I used MySQL to write queries and find useful information from the data. Finally, I created an interactive Power BI dashboard to present the findings in a simple and understandable way.

I also prepared a project report and a PowerPoint presentation to summarize the analysis and key insights.

## Dataset

The dataset contains customer shopping information, including age, product categories, purchase amounts, discounts, review ratings, and shopping preferences.

I used this data to explore customer purchasing patterns and understand how different factors relate to shopping behavior.

## Tools Used

- **Python** – Loading, cleaning, and analyzing the data
- **Pandas** – Working with the dataset
- **Jupyter Notebook** – Writing and running Python code
- **MySQL** – Storing data and performing SQL analysis
- **Power BI** – Creating an interactive dashboard
- **PowerPoint** – Presenting the project findings

## Project Steps

### 1. Loading the Data
Imported the CSV dataset into Python using Pandas and checked its structure, columns, and data types.

### 2. Exploratory Data Analysis (EDA)
Explored the dataset using summary statistics and checked for missing values and patterns in customer shopping behavior.

### 3. Data Cleaning
Handled missing values, standardized column names, and created an age group column to make customer analysis easier.

### 4. SQL Analysis
Loaded the cleaned data into MySQL and wrote SQL queries to analyze purchasing behavior, product categories, customer segments, and other relevant details.

### 5. Power BI Dashboard
Created an interactive dashboard with charts, key metrics, and slicers to make it easier to explore the data and understand the results.

### 6. Report and Presentation
Prepared a report and PowerPoint presentation to explain the project process and summarize the important findings.

## Dashboard Results

The Power BI dashboard allows users to explore different aspects of customer shopping behavior, such as:

- Customer distribution by age group
- Purchase patterns across product categories
- Customer spending and purchase amounts
- Discount usage and shopping preferences
- Review ratings and customer feedback

The dashboard makes it easier to compare different customer groups and identify patterns in the dataset.

## How to Run the Project

1. Download or clone this repository to your computer.
2. Install Python and the required libraries, including Pandas and NumPy.
3. Open the Jupyter Notebook and run the cells in order.
4. Set up MySQL and import the cleaned dataset.
5. Execute the SQL queries to perform the analysis.
6. Open the Power BI `.pbix` file in Power BI Desktop.
7. Update the data source settings if required.
8. Open the report and PowerPoint presentation to review the findings.
